# Install

Grab the `zook` binary and put it on your server's PATH.

```bash
make build            # produces bin/zook
sudo install -m 0755 bin/zook /usr/local/bin/zook
```

Then lay out a stack under your stacks root (default `/opt/stacks`) and deploy.
See the [commands](/docs/commands/) and [stacks](/docs/stacks/) docs.
